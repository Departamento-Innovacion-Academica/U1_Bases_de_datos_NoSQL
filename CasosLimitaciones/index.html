2.2.4 Casos de uso frecuentes

Las bases documentales son comunes en:

  • Comercio electrónico (catálogos).
  • Perfiles de usuarios.
  • Aplicaciones móviles.
  • Sistemas CMS.
  • Historiales clínicos flexibles.
  • Plataformas saas.
  • Microservicios.

Por ejemplo, un producto en e-commerce puede tener atributos distintos según categoría: talla, color, memoria, capacidad, marca o dimensiones[cite: 14].

2.2.5 Tecnologías representativas

Entre las plataformas documentales más reconocidas se encuentran:

  • MongoDB.
  • Couchbase.
  • CouchDB.
  • Azure Cosmos DB (modo documental).
  • Amazon DocumentDB.

MongoDB es una de las más adoptadas por su ecosistema, herramientas y lenguaje de consulta orientado a documentos (MongoDB Inc., 2024)[cite: 14].

2.2.6 Operaciones comunes

Las operaciones básicas incluyen:

  • Insertar documentos.
  • Buscar por atributos.
  • Actualizar campos específicos.
  • Eliminar documentos.
  • Crear índices.

Ejemplo en MongoDB

db.clientes.insertOne({ nombre: "Laura", ciudad: "Bogotá" }) db.clientes.find({ ciudad: "Bogotá" })

2.2.7 Ventajas principales

  1. Agilidad de desarrollo: se adapta fácilmente a cambios del negocio.
  2. Menor necesidad de joins: muchos datos relacionados pueden ir embebidos.
  3. Integración natural con JSON: ideal para APIs REST y aplicaciones web modernas.
  4. Escalabilidad: muchas plataformas soportan particionamiento automático.

2.2.8 Limitaciones a considerar

También existen desafíos:

  • Duplicación de datos en algunos diseños.
  • Joins menos naturales que SQL clásico.
  • Riesgo de documentos excesivamente grandes.
  • Necesidad de buen modelado inicial.

Por ello, la flexibilidad debe acompañarse de diseño cuidadoso[cite: 14].
