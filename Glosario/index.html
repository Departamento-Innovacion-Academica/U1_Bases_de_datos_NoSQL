Glosario de la unidad

BASE (Basically Available, Soft State, Eventually Consistent)

Modelo de consistencia utilizado en muchos sistemas NoSQL que prioriza la disponibilidad y la tolerancia a fallos en sistemas distribuidos, permitiendo que los datos alcancen consistencia de manera eventual.

Base de datos de grafos

Tipo de base de datos NoSQL que organiza la información mediante nodos y relaciones, permitiendo representar y analizar estructuras de datos altamente conectadas, como redes sociales o sistemas de recomendación.

Base de datos documental

Modelo de base de datos NoSQL que almacena información en documentos estructurados, generalmente en formatos como JSON o BSON, lo que permite mayor flexibilidad en la estructura de los datos.

Base de datos clave-valor

Modelo de almacenamiento NoSQL que organiza los datos mediante pares de clave y valor, permitiendo operaciones rápidas de lectura y escritura en aplicaciones que requieren alto rendimiento.

Base de datos columnar

Tipo de base de datos NoSQL que almacena la información organizada por columnas en lugar de filas, optimizando el procesamiento de grandes volúmenes de datos y consultas analíticas.

Big Data

Conjunto de tecnologías y enfoques utilizados para almacenar, procesar y analizar grandes volúmenes de datos caracterizados por su volumen, velocidad y variedad.

Consistencia eventual

Modelo de consistencia en sistemas distribuidos donde los datos pueden no ser inmediatamente consistentes en todos los nodos, pero se sincronizan con el tiempo hasta alcanzar un estado consistente.

Escalabilidad horizontal

Capacidad de un sistema para aumentar su capacidad agregando más servidores o nodos al sistema en lugar de mejorar el hardware de un único servidor.

Modelo de datos NoSQL

Forma en que los datos son estructurados y almacenados en bases de datos NoSQL, permitiendo esquemas flexibles que se adaptan a diferentes tipos de información y aplicaciones.

NoSQL (Not Only SQL)

Categoría de sistemas de gestión de bases de datos diseñados para manejar grandes volúmenes de datos y estructuras flexibles, especialmente en entornos distribuidos y aplicaciones modernas.

Replicación de datos

Proceso mediante el cual la información almacenada en una base de datos se copia y mantiene sincronizada en múltiples nodos o servidores para mejorar la disponibilidad y tolerancia a fallos.

Sistema distribuido

Arquitectura en la que múltiples nodos o servidores trabajan de manera coordinada para almacenar, procesar y gestionar información dentro de una misma plataforma de datos.

Teorema CAP

Principio fundamental en sistemas distribuidos que establece que una base de datos solo puede garantizar simultáneamente dos de las siguientes tres propiedades: consistencia, disponibilidad y tolerancia a particiones.
