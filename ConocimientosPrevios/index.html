Fundamentos de bases de datos relacionales

comprensión de los principios básicos de las bases de datos relacionales, incluyendo conceptos como tablas, registros, claves primarias, relaciones entre entidades y restricciones de integridad.

Lenguaje SQL básico

capacidad para realizar consultas simples mediante el uso de instrucciones SQL, tales como operaciones de selección, filtrado, inserción, actualización y eliminación de datos en sistemas de bases de datos relacionales.

Conceptos generales de modelado de datos

conocimiento de los principios básicos del diseño de bases de datos, incluyendo la estructuración de entidades, atributos y relaciones en un modelo de información.

Nociones básicas de sistemas de información

comprensión general de cómo los sistemas de información almacenan, procesan y gestionan datos dentro de aplicaciones empresariales o plataformas digitales.

Conceptos introductorios de análisis de datos

familiaridad básica con el uso de datos para generar información que apoye procesos de análisis o toma de decisiones.

Uso básico de herramientas tecnológicas

capacidad para utilizar herramientas informáticas y plataformas digitales utilizadas en entornos académicos y profesionales para el manejo y análisis de información.
